# 各模組說明

每個模組列出：功能、主要前端檔案、後端接點、權限。

## 戰情總覽（Dashboard）
- 4 張統計卡（據點低庫存／總量不足／即將過期／已過期）、各據點物資統計表（可「查看物資」深連結）、低於警戒水位、全系統總量不足、即期物資。
- 檔案：`pages/Dashboard.tsx`
- 後端：`supply_item_resolved`、`location_low_stock_view`、`global_low_stock_view`、`supply_item`
- 權限：全部登入者

## 物資管理（物資清單）
- 篩選（關鍵字/據點/種類 + 分類快切）、跨據點統計、每列操作：**詳細資料 / 編輯 / 物資轉移 / 刪除**、照片點擊放大預覽（內含中文下載）、**匯出 Excel**。
- 檔案：`pages/SupplyItems.tsx`、`lib/imageUpload.ts`、`lib/excelExport.ts`
- 後端：`supply_item`（直接 CRUD，RLS）；編輯/刪除走 client update
- 權限：詳細=全部；編輯/轉移=Admin/Cadre；刪除=Admin

## 物資入庫（StockIn）
- 種類→名稱→規格連動、數量/據點/效期/圖片/備註，成功後回物資清單。
- 檔案：`pages/StockIn.tsx`、`components/SupplyItemForm.tsx`、`hooks/useCascadingCatalog.ts`
- 後端：`supply_item` insert；圖片上傳 `items` bucket

## 出庫 / 捐贈 / 報廢
- 共用 `StockBatchPicker`（挑既有批次 + 即期快選）；出庫扣量、捐贈加量、報廢扣量（含原因）。
- 檔案：`pages/SupplyOutbound.tsx` / `SupplyDonation.tsx` / `SupplyDisposal.tsx`、`components/StockBatchPicker.tsx`、`lib/stockBatch.ts`
- 後端：`outbound-create` / `donation-create` / `disposal-create`（Edge Function → RPC）
- 紀錄頁：物資名稱欄、篩選、Excel 匯出

## 物資轉移（Transfer）
- 多品項一次轉移、狀態機（建立/確認/取消）；物資清單「轉移」按鈕帶 `?supplyItemId=` 預選。
- 檔案：`pages/SupplyTransfer.tsx`
- 後端：`transfer-create` / `transfer-confirm` / `transfer-cancel`
- 權限：Admin/Cadre

## AI 影像入庫（AIStockIn）
- 文字或照片辨識 → 待確認 → 人工核對 → 正式入庫；辨識紀錄頁。
- 檔案：`pages/AIStockIn.tsx`、`lib/functionError.ts`、`lib/imageUpload.ts`
- 後端：`ai-stockin-recognize` / `ai-stockin-confirm`；`ai_stock_in_settings`、`catalog_synonym`

## 領取分析（RecipientAnalysis）
- 領用人排行、次數、不同物資數。檔案：`pages/RecipientAnalysis.tsx`；後端：`recipient_analysis_view`

## 據點管理（SupplyLocations）
- 據點 CRUD、篩選（關鍵字/座標狀態/聯絡資訊）。檔案：`pages/SupplyLocations.tsx`；後端：`supply_location`（RLS：Admin 寫）

## 庫存種類設定（InventoryTypes）
- 目錄定義、規格、各據點安全庫存門檻。檔案：`pages/InventoryTypes.tsx`；後端：`inventory_item_definition/variant`、`location_inventory_safety_stock`

## 帳號管理（AccountManagement）
- 新增帳號（彈窗）、編輯、停用（刪除）、LINE 綁定碼/解除。檔案：`pages/AccountManagement.tsx`；後端：`account-admin`（防呆：不能停最後一個 Admin/自己）

## 系統設定（AdminSettings）
- LINE 通知設定、AI 智慧入庫設定（金鑰於此輸入，存資料庫）。檔案：`pages/AdminSettings.tsx`；後端：`admin-settings`

## 手機頁面（MobileFeatures）
- 全螢幕：物資查詢 / 物資領用 / 物資轉讓 / 影像入庫，供 LINE 圖文選單串接；工程模式啟動器可預覽。
- 檔案：`pages/MobileFeatures.tsx`、`pages/mobile-original.css`
- 網址：`/mobile/inventory|pickup|transfer|vision`
