# 使用說明書（給使用者）

正式站：<https://bill1114.github.io/ResourceSharingPlatform-Web/>

---

## 一、登入
1. 開啟網站，輸入**帳號**與**密碼**，按「登入」。
2. 忘記密碼或需要新帳號，請聯絡系統管理員。
3. 閒置過久可能被登出，重新登入即可。

## 二、看整體狀況（戰情總覽）
登入後首頁即為「戰情總覽」：
- 上方 4 個數字：據點低庫存、總量不足、即將過期、已過期。
- 「各據點物資統計」表：點該據點的「查看物資」可看該據點的物資清單。
- 下方列出低於警戒水位、全系統總量不足、即期物資。

## 三、物資管理
選單「**物資管理 ▾ → 物資清單**」：
- 上方「篩選條件」：輸入關鍵字、選據點/種類，或用分類快切（全部/無效期/有效期/冷凍食品）。
- 「依物資統計」：跨據點加總各品項總量與最近效期。
- 每一列右側「操作」：
  - 👁 **詳細資料**：看完整資訊。
  - ✏️ **編輯**：修改數量、效期、安全庫存、備註或更換圖片。
  - ⇄ **物資轉移**：帶著這項物資跳到轉移頁。
  - 🗑 **刪除**：停用該筆（管理員）。
- 點**照片縮圖**會放大顯示，視窗內可「下載（中文檔名）」。
- 右上「**匯出 Excel**」：把目前篩選結果匯出成 Excel 檔。

## 四、物資入庫（新增庫存）
「物資管理 ▾ → **物資入庫**」：
1. 選分類（無效期/有效期/冷凍食品）。
2. 依序選物資種類 → 名稱 → 規格。
3. 填數量、所在據點、有效期限（有效期物資必填）、（可）上傳圖片、備註。
4. 按「確認入庫」→ 自動回到物資清單並顯示成功訊息。

## 五、物資出庫 / 捐贈 / 報廢
「物資管理 ▾ → 物資出庫 / 物資捐贈 / 物資報廢」：
1. 選據點 → 用分類快切/下拉挑到要異動的**物資批次**（上方會列出即期/已過期建議優先處理）。
2. 出庫：填數量、領用人、聯絡方式；捐贈：填數量、捐贈者；報廢：填數量、原因。
3. 送出後回到對應**紀錄頁**並顯示成功訊息。

## 六、跨據點轉移
「物資管理 ▾ → **物資轉移**」（管理員/幹部）：
1. 選來源據點、目標據點（不可相同）。
2. 選要轉移的物資與數量（可多筆）。建立時**立即扣掉來源庫存**。
3. 目標據點在「紀錄查詢 ▾ → 轉移紀錄」按「**確認送達**」才會入庫；按「**取消**」則退回來源。

## 七、AI 影像入庫
「物資管理 ▾ → **AI 智慧入庫**」：
1. 選據點，輸入文字描述**或**上傳照片，按「開始辨識」。
2. 系統列出辨識結果，**逐項核對**品項/數量/效期。
3. 按「確認並正式入庫」→ 資料寫入庫存，照片會出現在物資清單。

## 八、紀錄查詢
「**紀錄查詢 ▾**」：出庫/捐贈/報廢/轉移/AI 辨識紀錄、領取分析。各頁可篩選、匯出 Excel。

## 九、常見問題
- **看到舊畫面？** 按 `Ctrl + F5` 強制重新整理。
- **圖片下載檔名是中文嗎？** 是，點縮圖放大後用「下載」按鈕，存下的就是中文檔名。
- **手機/LINE 使用**：從 LINE 圖文選單開啟功能，第一次會要求登入，之後直接進入。
