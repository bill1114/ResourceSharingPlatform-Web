# 程式結構（前端）

## 目錄總覽

```
ResourceSharingPlatform-Web/
├─ src/
│  ├─ main.tsx              進入點：掛載 Providers（Auth / 工程模式）與 HashRouter
│  ├─ App.tsx               路由表（所有頁面對應網址、權限包裝）
│  ├─ index.css             全域樣式（badge 放大、.col-min 欄寬工具…）
│  ├─ components/           跨頁共用元件
│  ├─ pages/                各功能頁面
│  ├─ hooks/                共用邏輯 hook
│  ├─ lib/                  純函式工具與 supabase client
│  └─ types/db.ts           資料表型別定義
├─ supabase/
│  ├─ migrations/*.sql      資料庫結構、View、RLS、RPC（依時間戳順序套用）
│  └─ functions/*/index.ts  Edge Functions（每個資料夾一支，單檔自足）
├─ .github/workflows/deploy-pages.yml   自動部署
├─ docs/                    本文件集
└─ Markdown/BackupPlan.md   備份機制說明
```

## components/

| 檔案 | 職責 |
|---|---|
| `AppShell.tsx` | 桌面外殼：頂部導覽列（戰情總覽／物資管理▾／紀錄查詢▾／系統管理▾）＋ `<Outlet/>` |
| `ProtectedRoute.tsx` | 未登入導向 `/login`，並記住原本要去的路徑（登入後導回） |
| `RoleGate.tsx` | 依角色顯示內容；`fallback` 可指定無權限時的畫面（手機頁用） |
| `EngineeringRoute.tsx` | 工程模式才可進入（手機功能啟動器用） |
| `FlashMessage.tsx` | 讀取路由 state 的 `flash` 訊息，顯示成功提示後清除 |
| `SupplyItemForm.tsx` | 「物資入庫」新增表單（種類→名稱→規格連動、圖片上傳），入庫頁與物資清單共用 |
| `StockBatchPicker.tsx` | 出庫／捐贈／報廢共用的「挑既有批次」區塊＋即期快選面板 |

## pages/

| 檔案 | 匯出的頁面 | 網址 |
|---|---|---|
| `Login.tsx` | 登入 | `/login` |
| `Dashboard.tsx` | 戰情總覽 | `/` |
| `SupplyItems.tsx` | 物資清單（含詳細/編輯/放大圖/Excel） | `/supply-items` |
| `StockIn.tsx` | 物資入庫 | `/stock-in` |
| `SupplyLocations.tsx` | 據點管理 | `/supply-locations` |
| `SupplyOutbound.tsx` | 出庫（Create）＋出庫紀錄（Index） | `/outbound/create`, `/outbound` |
| `SupplyDonation.tsx` | 捐贈＋捐贈紀錄 | `/donations/create`, `/donations` |
| `SupplyDisposal.tsx` | 報廢＋報廢紀錄 | `/disposals/create`, `/disposals` |
| `SupplyTransfer.tsx` | 轉移＋轉移紀錄 | `/transfers/create`, `/transfers` |
| `AIStockIn.tsx` | AI 影像入庫＋辨識紀錄 | `/ai-stockin/create`, `/ai-stockin` |
| `RecipientAnalysis.tsx` | 領取分析 | `/outbound/recipient-analysis` |
| `AccountManagement.tsx` | 帳號管理 | `/admin/accounts` |
| `AdminSettings.tsx` | LINE 通知設定＋AI 設定 | `/admin/line-settings`, `/admin/ai-settings` |
| `InventoryTypes.tsx` | 庫存種類設定 | `/admin/inventory-types` |
| `MobileFeatures.tsx` | 手機頁面（查詢/領用/轉讓/影像入庫）＋啟動器 | `/mobile/*`, `/engineering/mobile-features` |

## hooks/

| 檔案 | 職責 |
|---|---|
| `useAuth.tsx` | 登入狀態、`profile`（角色/據點/顯示名）、`signIn/signOut`；帳號轉假 email |
| `useEngineeringMode.tsx` | 隱藏的工程模式開關（Ctrl+Shift+E，存 localStorage） |
| `useCascadingCatalog.ts` | 目錄（種類→名稱→規格）連動下拉，供入庫表單 |
| `useItemPicker.ts` | 挑「既有庫存批次」連動（含分類篩選），供出庫/捐贈/報廢 |

## lib/

| 檔案 | 職責 |
|---|---|
| `supabaseClient.ts` | 建立 supabase-js client（讀 `VITE_SUPABASE_*`） |
| `enums.ts` | 角色/庫存分類/報廢原因/轉移狀態等常數與顯示名、badge 樣式 |
| `colors.ts` | 據點色（`(id-1)%8`）、種類色（字串雜湊），移植自 .NET |
| `imageUpload.ts` | 物資圖片上傳、中文下載檔名產生、AI 照片搬進 items、換圖 |
| `stockBatch.ts` | 效期判讀、即期清單查詢、批次下拉文字 |
| `functionError.ts` | 還原 Edge Function 真正的中文錯誤訊息（supabase-js 會吞掉） |
| `excelExport.ts` | 前端產生 `.xlsx`（SheetJS） |

## 進入點與 Provider 疊法（`main.tsx`）

```
HashRouter
  └ EngineeringModeProvider
      └ AuthProvider
          └ <App/>   ← 路由表
```
