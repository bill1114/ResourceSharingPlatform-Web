## 2026-09-17　權限細化、AI 手動入庫、忘記密碼、物資明細分組、分析中心、拖拉排序等

### 功能修改
- **戰情總覽**：抬頭改「物資總攬」；即將過期天數 30→**10 天**；登入後全部角色統一導向戰情總覽（保留 LINE `/mobile/*` 深連結）；**全體 30 分鐘閒置自動登出**。
  - 小幫手：卡片把「總量不足」換成「**據點總物資**」（馬卡龍綠、最左，連自己據點物資清單）；不顯示「待處理需求」。
  - 待處理需求：幫主只看自己據點提出的；**已過期**卡片與清單，幫主/小幫手只看自己據點。
- **物資清單**：新增「**有效期限區間**」查詢；抬頭改「物資清單」；安全庫存＝據點門檻（唯讀）；**數量0超過7天自動隱藏**＋眼睛只顯示已隱藏；幫主可操作自己據點、別據點唯讀、小幫手唯讀。
- **物資明細**：改依**種類/名稱/規格分組收合**，右側按鈕展開看明細；新增**時間欄**；欄寬平均；目前數量改**累加**並修正「建立批次/轉移」造成的錯誤負數；已隱藏以**品項**計數；幫主只看自己據點。
- **捐贈紀錄**：移除捐贈者排行，改成內嵌「**總量不足**」表格。
- **報廢紀錄**：幫主只看自己據點；新增報廢僅總管。
- **AI 智慧入庫**：多品項批次、顯示照片、版面對齊；新增「辨識中/辨識失敗」狀態與返回/重整出口；新增「**手動輸入品項**」（AI 漏判時人工補、直接寫入庫存）。
- **庫存種類設定**：可**拖拉自訂排序**；募資觸發點改門檻×0.9。
- **匯出 Excel**：各報表底部加「總計」。
- **新功能**：
  - **操作紀錄（稽核 Log）**：系統管理→操作紀錄（總管），記錄登入/庫存異動/資料維護/申請。
  - **分析中心（第一版）**：紀錄查詢→分析中心（總管），總覽＋自選資料來源/維度/圖表＋匯出。
  - **忘記密碼（自助重設）**：登入頁輸入帳號＋新密碼即可重設；總管在帳號管理看到「近 7 天曾自助改密碼」須注意名單（7 天後自動消失、可手動解除）。

## 2026-09-01　稽核 Log、查看物資權限還原、物資明細幫主限自己據點、測試清單

### 功能修改
- **新增「操作紀錄」稽核 Log**（系統管理 → 操作紀錄，僅總管）：集中記錄 誰／何時／做了什麼
  （登入登出、庫存異動、資料維護、申請）。各操作成功後由前端寫入 `activity_log`。可依
  關鍵字／分類／據點／日期區間 篩選、看細節、匯出 Excel。
- **戰情總覽「查看物資」還原給全部角色**；`/supply-items` 開放所有登入者：
  - 小幫手＝唯讀檢視（只有 詳細／匯出）。
  - 幫主＝可操作**自己據點**的物資（詳細／編輯／轉移／刪除／入庫），別據點唯讀。
  - 總管＝不限。選單仍維持「物資清單」僅總管（其他角色經由查看物資進入）。
- **物資明細（ItemLedger）幫主只看自己據點**並可調整，看不到別據點（總管不限）。
- 新增 `docs/測試項目.md`：自動化測試項目清單（A 靜態關卡／B 單元／C E2E），供 GitHub Actions 使用。

### 資料庫變更（migration）
- `20260831000004_activity_log.sql`：新增 `activity_log` 表（誰/何時/action/category/target/
  location/summary/detail）＋索引＋RLS（檢視限總管、寫入限本人 `actor_id = auth.uid()`）。
- 其餘為前端權限調整，無資料庫結構變更。

### 文件更新
- 新增本次更新紀錄與 `docs/測試項目.md`。
- `docs/模組說明.md`：新增「操作紀錄」模組；更新物資清單（角色操作權限）、物資明細（幫主限自己據點）。

## 2026-08-31　戰情總覽全域可見、安全庫存來源統一、募資觸發點、匯出總計

### 功能修改
- **AI 智慧入庫**：一張照片／一段文字可含多項物資→**批次入庫**（桌面版消化辨識回傳的 logs[]，逐項核對/移除）；辨識前後**顯示照片**；版面對齊物資入庫（步驟卡片、信心徽章、日曆選日期）。手機版同步修正批次與照片預覽。
- **物資入庫**：日期改回**日曆**選擇；規格可選「**無（未指定）**」先入庫，之後由總管在庫存種類設定新增規格、再回物資清單編輯補分類。
- **報廢紀錄**：幫主隱藏「新增報廢」按鈕（報廢建立僅總管；幫主走申請報廢）。
- **領用紀錄**：據點篩選只列使用中據點。
- **物資明細**：「目前數量」改為依時間**累加**各筆增減後的當下數量（畫面與匯出一致）。
- **戰情總覽全域可見**：卡片數字、各據點狀態、點卡片進去的清單，對**全部角色一致**顯示全部據點（幫主/小幫手不再只看自己據點）。「查看物資」按鈕僅總管。
- **權限（看得到但不能操作別據點）**：物資明細「調整／刪除」對非總管只在自己據點顯示；狀態清單的「舉手／申請報廢」是**請求類**功能（送總管審核），依設計總管＋幫主可用、小幫手無。
- **安全庫存來源統一**：物資清單「安全庫存」＝「庫存種類設定 → 據點門檻」（唯讀顯示、與低庫存判斷同源）；編輯物資的安全庫存改唯讀、不可修改。
- **募資觸發點**：全系統安全總量的觸發點改為 **門檻 × 0.9**（原為 門檻 − 安全庫存量）。
- **匯出 Excel**：報表底部新增「**總計**」列（物資明細增減數量、領用/捐贈/報廢/轉移數量、物資清單數量）。

### 資料庫變更（migration，需依序執行）
- `20260831000001_dashboard_global_status.sql`：新增 `dashboard_location_status`、`dashboard_summary` 兩支 **SECURITY DEFINER** 彙總 view（只回統計數字、不回明細），授權 authenticated；戰情總覽改讀這兩支。
- `20260831000002_supply_item_global_read.sql`：`supply_item` 的 **SELECT RLS 放寬**為所有登入者可讀全部據點；**寫入政策不變**（新增/修改/刪除仍限總管或所屬據點）。
- `20260831000003_global_trigger_ninety_percent.sql`：`global_low_stock_view` 與 `dashboard_summary` 的募資判斷改為 `當前總庫存 < 門檻 × 0.9`。
- 另有唯讀盤點腳本 `diagnostics/db_inventory.sql`（非 migration，供整理資料庫前確認現況）。
- 安全庫存來源統一為既有 `location_inventory_safety_stock`（無新結構）；物資清單編輯不再寫回此表，改由「庫存種類設定」維護。
